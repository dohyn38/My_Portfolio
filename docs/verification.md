# 포트폴리오 기능 검증 기록

이 문서는 Codex가 공개 사이트에서 실제로 수행한 검사를 정리한 중간 기록입니다. 사용자가 직접 수행한 검사와 구분하며, 최종 제출 버전에 대한 전체 합격 판정은 아닙니다.

## 검사 환경과 범위

- 도구: Codex 내장 브라우저
- 브라우저 엔진·버전 및 정확한 검사 시각: 당시 별도 수집하지 않아 미표시
- 검사 대상: https://dohyn38.github.io/My_Portfolio/
- 상세 페이지: https://dohyn38.github.io/My_Portfolio/projects/portfolio/
- 화면 폭: 지정 검사에서 1440px, 768px, 390px 사용
- 검사 당시 배포 커밋 SHA: 미확인. 최종 제출 시 main SHA와 Actions 실행을 연결하여 재검증 필요
- 원본 캡처: 대화의 도구 결과에서 화면을 확인했으나 이 저장소에 증빙 이미지 파일로 저장하지 않음

## 문제 해결과 재검증 사례

### 공통 헤더 메뉴 잘림 개선

- 관찰: 상세 페이지 화면에서 상단 메뉴가 오른쪽에서 일부 잘려 보임.
- 원인 판단: 사용자 정의 메뉴 보완이 홈에 한정되어 있고, 공통 메뉴의 줄바꿈과 폭 처리가 부족함.
- 수정 위치: site/assets/css/extended/custom.css
- 변경: 공통 헤더와 메뉴의 flex 줄바꿈, 메뉴·로고 항목의 너비 제한, 작은 화면의 메뉴 행 배치 적용.
- 재검증: T04에 기록한 홈·상세의 세 화면 폭 검사와 홈 메뉴 배치 복구 검사 수행.
- 결과: 검사한 범위에서 메뉴 잘림과 문서 가로 넘침 없음.
- 관련 커밋: https://github.com/dohyn38/My_Portfolio/commit/2bbad06
- 한계: 위 링크는 확인한 수정 커밋의 단축 SHA 주소이며, 검사 당시 배포가 정확히 이 SHA였는지는 별도 확인하지 않음. 최종 보고서에는 전체 SHA와 Actions 실행 연결 필요.

### 소개 GitHub 아이콘 확대 오류

- 관련 기준: P15(아이콘 표시), P31·P32(화면 배치), P65(문제 해결과 재검증). 링크 이름은 P46과 관련되지만 이 크기 수정만으로 각 항목 전체 충족을 판정하지 않음.
- 관찰: ABOUT ME 제목 옆에 작은 GitHub 아이콘을 배치하려 했으나 공개 화면에서 아이콘이 크게 표시됨.
- 확인 방법: Codex 내장 브라우저로 공개 홈의 #about에 접속하고 링크·span·SVG의 실제 표시 크기를 측정함.
- 측정 결과: 링크와 span의 폭은 각각 1080px, SVG는 1080×1080px로 측정됨. 로컬 CSS에는 SVG 22×22px 규칙이 존재했지만 검사한 공개 화면에서는 이 제한이 유효하게 적용되지 않음.
- 원인 판단: SVG의 크기가 제한되지 않아 컨테이너 폭으로 확장됨. 로컬 CSS와 배포 결과 사이에 차이가 있었으나 CSS 누락·캐시·배포 버전 중 어느 것이 근본 원인인지는 확정하지 않음.
- 수정 위치: site/layouts/home.html. 기존 관련 스타일은 site/assets/css/extended/custom.css에 있음.
- 수정 내용: 기존 테마 GitHub SVG를 재사용하면서 출력 SVG에 width·height 22와 인라인 width·height·max-width 22px를 지정함. 링크 영역은 32×32px로 지정하고 제목 옆 배치와 프로필 주소·접근 가능한 이름을 유지함.
- 예상 결과: 제목 옆 아이콘이 22×22px로 표시되고 클릭하면 https://github.com/dohyn38 로 이동함.
- 재검증 상태: 대기. 로컬 파일 수정은 완료했으나 수정본 배포 후 실제 크기와 배치·링크 동작은 아직 확인하지 않음.
- 다음 확인: 최종 배포 SHA·Actions 성공 확인 → 새로고침 → SVG 22×22px 측정 → PC·모바일 제목 배치와 Tab·Enter 조작 확인.
- 증빙: 수정 커밋 URL, 검사 환경·시각, 수정 전후 캡처는 추가 기록 필요. 기존 측정은 대화의 도구 출력에 남아 있음.

## 제출 전 남은 작업

- 실제 자기소개·학습 목표·활동 내용 작성 및 임시 문구 제거 후 화면 재검사
- 최종 main의 유효 커밋 집계와 필수 파일 추적 확인
- README의 설치·실행 명령 실제 검증
- 최종 main push 자동 실행 및 빌드·배포 성공 확인
- 실제 200% 확대 검사
- 최종 결과 이미지 사용 시 이미지 관련 검사
- 최종 검사 환경·버전·시각·화면 폭·SHA·Actions·증빙 캡처 기록

코드 변경 없는 정상 검사에 대해 개수 확보 목적의 별도 커밋을 만들지 않습니다. 이 문서는 실제 수행한 검증 결과를 모아 문서화하는 작업입니다.
